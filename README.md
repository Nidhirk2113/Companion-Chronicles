## 🚀 Introduction  
**CompanionChronicles** is a database-driven web application developed to modernize and manage operations in the veterinary domain. Built using the **MERN stack** (MongoDB, Express.js, React.js, and Node.js), the platform enables streamlined handling of patient records, appointments, user roles, and service management — all within a secure and responsive system.

## ✨ Features  
- 🐾 **Patient Management**: Add, update, and maintain detailed records of animal patients including species, medical history, and treatment plans.  
- 👨‍⚕️ **User Authentication**: Role-based login/registration system for veterinary staff and admins.  
- 📅 **Appointment Scheduler**: Enables efficient appointment booking and tracking.  
- 📱 **Responsive Design**: Fully functional across desktop, tablet, and mobile devices.  
- 🗃️ **Inventory Management (Upcoming)**: Track medications and supplies used in treatments.

## ⚙️ Installation  

Clone the repository:
```bash
git clone https://github.com/iffahaafreen/CompanionChronicles.git
cd CompanionChronicles
```

Install server dependencies:
```bash
cd server
npm install
```

Install client dependencies:
```bash
cd ../client
npm install
```

Start the backend server:
```bash
cd ../server
npm start
```

Start the frontend (in a separate terminal):
```bash
cd ../client
npm start
```

---

## 💻 Usage  
Once both the client and server are running:

- Open your browser and navigate to `http://localhost:3000`
- Login or register as a veterinarian or admin
- Access patient dashboards, book appointments, and manage daily clinical tasks
